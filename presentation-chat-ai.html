Product Presentation

AI-Powered Dealership Chat

Chat AI engages website visitors, answers questions from CMS and inventory, captures leads, schedules appointments, and notifies dealership teams.

  • Real-time web chat + specialist takeover
  • OpenAI-assisted responses and intent handling
  • CRM registration and analytics events

Problem We Solve

Customer Friction

Visitors leave websites when responses are slow or inventory info is hard to find.

Lead Loss

Leads are missed without structured capture, CRM sync, and routing.

Appointment Drop-off

Scheduling fails when business hours and availability are not validated.

Operational Blind Spots

Teams need event logs, notifications, and GA4 signals for performance tracking.

System Architecture

Core Runtime

  • WebChat Service (REST + WebSocket gateway)
  • Chat Engine (AI orchestration + state machine)
  • Queue Processor (async CRM + notifications + GA4)

Platform Services

  • Platform Resources API (hours/settings/CMS)
  • Account Management APIs
  • Platform Notifications + URL Shortener

Data & Messaging

  • DynamoDB: conversation state/events/settings
  • OpenSearch: inventory lookup
  • S3: UI settings, images, embeddings
  • Redis: pub/sub + queueing

External Integrations

  • OpenAI (responses + embeddings)
  • CRMs: DealerSocket, VinSolutions, ELEAD, Unified
  • Twilio, Auth0, GA4

End-to-End Flow

  1. User opens chat -> WebChat WebSocket session starts.
  2. Message forwarded to Chat Engine; state saved in DynamoDB.
  3. AI decides response/tooling (CMS, inventory, scheduling).
  4. Bot response pushed in real time via Redis pub/sub.
  5. Lead events trigger immediate or queued CRM registration.
  6. Notifications + GA4 events emitted for reporting and operations.

Operations & Reliability

Scalability

  • WebSocket fan-out using Redis pub/sub
  • Async lead queue with retries/backoff
  • Versioned inventory indexing with alias switching

Observability

  • DynamoDB event trail for conversations
  • CloudWatch service logs
  • GA4 event stream for behavior metrics

Known Risks & Mitigations

Risk Impact Mitigation
OpenAI/API outages Response quality or latency degradation Fallback messaging + retries + monitoring
CRM integration failures Lead drop or delayed registration Queue retries, failure logs, token health checks
Inventory index mismatch Poor vehicle search results Alias validation and index version controls
Subscriber filtering too strict Missed operational notifications Principal rules audit and test subscribers
